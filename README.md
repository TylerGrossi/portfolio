# Portfolio

Personal portfolio site: data analytics, quantitative finance and sports modeling projects.

Static site, no build step: `index.html` plus screenshots in `assets/shots/`. Deployed on Vercel.

Project facts come from `../RESUME-BRIEF.md` in the parent Projects folder; keep numbers in sync with it.
To refresh screenshots, capture each live URL at 1600x1000 and save as a 1280px-wide JPEG at `assets/shots/<id>.jpg`.
